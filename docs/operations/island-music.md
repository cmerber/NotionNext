# 小岛声场

入口：`https://qcode.im/music`。音乐人：晴岑来。导航和首页文案已经站主确认。

## 内容与播放

- 两首作品来自站主的本地 MP3：《晚点也没关系》《羊光正好》，封面取自音频内嵌图片。
- 网站显式标注 AI 辅助创作。原音频不改动，支持 MP3 和逐句 LRC 下载。
- 《晚点也没关系》沿用已校对的 47 句演唱歌词和两行署名；《羊光正好》用内嵌原歌词进行 76 句机器强制对齐，仍可按实际听感在 Notion 校正。
- 播放由访客点击开启，包含唱片动效、暂停、上一首/下一首、进度、音量、单曲循环、跟随歌词、点击歌词跳转和歌曲分享链接。
- 分享区可选择本站歌曲链接或 QQ 音乐单曲链接，点击直接复制。本站链接带歌曲标识，打开后选中对应作品。
- 当前歌词以实际音频播放时钟更新并居中；手动滚动歌词暂停跟随 4 秒后恢复，点击「恢复跟随」、重新播放或跳转进度也会恢复。触碰歌词区域本身不会关闭跟随。
- 音乐平台入口只使用已经核实的地址；尚无核实的歌手直达地址时，明确标注为 QQ 音乐搜索入口。

## Notion 音乐库

管理页位于「橙子星球」数据库下：`https://app.notion.com/p/409c2c42b276806983fde5029eca6d70`。

该管理页在博客发布库保持 Draft，不作为普通文章发布。其下的独立音乐数据库管理作品，只有勾选「发布」的行才会同步到音乐页。

| 字段                              | 类型   | 用途                                    |
| --------------------------------- | ------ | --------------------------------------- |
| 歌名                              | 标题   | 作品名称                                |
| 歌曲ID                            | 文本   | 稳定英文标识，如 wan-dian，决定分享链接 |
| 音乐人                            | 文本   | 默认晴岑来                              |
| 发布                              | 复选框 | 是否公开同步                            |
| 音频                              | 文件   | 直接上传 MP3，不使用临时外链            |
| 封面                              | 文件   | JPG 或 PNG                              |
| LRC歌词                           | 文件   | 带时间戳的 UTF-8 LRC                    |
| 歌词文本                          | 文本   | 无 LRC 文件时使用的逐句 LRC 文本        |
| 时长（秒）                        | 数字   | 音频长度                                |
| 标签                              | 单选   | 作品简短主题                            |
| 一句话                            | 文本   | 歌曲列表里的短句                        |
| 创作手记                          | 文本   | 播放器里的作品说明                      |
| 排序                              | 数字   | 从小到大                                |
| 色调                              | 单选   | dusk 或 spring                          |
| QQ音乐、酷狗音乐、网易云音乐、B站 | URL    | 歌曲或音乐人主页                        |

GitHub 仓库 Secrets 保存 `NOTION_MUSIC_TOKEN` 和 `NOTION_MUSIC_DATABASE_ID`，不在代码、网页或日志中保存令牌。该连接只需访问音乐管理页及其子数据库。配置并验证后，将仓库变量 `NOTION_MUSIC_ENABLED` 设为 `true` 启用同步；未配置时跳过任务。

工作流 `Sync music from Notion` 支持手动触发，并在每小时第 17 分钟尝试同步（GitHub 排队可能延迟）。同步把 Notion 的限时附件复制到仓库的稳定资源路径，提交变更后由现有 Vercel Git 集成构建网站。无内容变化不提交。任何公开歌曲缺少音频、下载失败、歌词越界或平台链接不合法时，同步失败并保留上一版目录；不会发布一半的目录。GitHub Actions 页面可查看每次成功或失败结果。

首次正式部署和首次工作流成功，需要分别验证；代码准备完成不等于定时同步已成功。

2026-10-30 已完成首次云端同步验证：[成功任务 41032046405](https://github.com/cmerber/NotionNext/actions/runs/41032046405)，同步产生的提交 `aa26b3f9a27c21d6bfce69a7cfb9a8b6dfc4b7dd` 已由 Vercel 成功部署。此前零 job 的异常队列记录不阻挡这次新任务。每小时触发已启用；GitHub 调度和网站构建仍需要时间。
