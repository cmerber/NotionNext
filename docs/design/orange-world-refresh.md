# Orange：从 3D 首页到完整的小岛主题

## 参考核对

用户提供的小红书笔记：

- [五个网页审美资源](https://www.xiaohongshu.com/explore/6a6821f600000000090369c3)：页面评论区给出了以下五个名称；公开视频画面核对到 Aceternity UI。逐一查看官网，功能如下，不沿用视频中“全部免费”的笼统说法。
- [微缩门店](https://www.xiaohongshu.com/explore/6ad076ec000000001801329a)：公开说明包含视角、昼夜、可旋转模型、售货机和自动门。当前网页的视频未能完整连续播放，因此未声称已验证其全部动作。借鉴的是“物件操作产生可见结果，并连接实际业务”的思路。

主参考选 React Bits 与 Aceternity UI；所有界面代码针对现有 NotionNext 自行实现，未复制付费源码，也未购买或引入模板。3D 仍沿用现有 Three.js 场景。

## 连贯体验

- 工作室 → 发现四个角落、摘橙子获得一篇真实笔记 → 文章阅读 → 分类/归档 → 返回小岛。
- 首页、归档、分类、正文和关于页共享松绿、陶土、暖纸色、轨道和纸质书的视觉语言。
- 正文有响应式目录、当前位置、阅读进度、行宽选择、引用与代码样式、标签、前后篇和原评论。锁定文章不会渲染正文或生成目录。
- 悬浮主题条默认隐藏；在 Orange 页脚使用“外观与主题”进入现有面板。站点管理员可用 THEME_SWITCH_FLOATING=true 恢复悬浮条。
- 主题面板只在打开时创建预览内容，避免隐藏状态仍加载整批主题封面。小岛足迹只存放在当前浏览器标签页的 sessionStorage，文章往返保留进度，不上传。

## 性能策略

- 按材质和目的地合并静态家具与花草；不把眨眼、挥手、书本、抽屉等动态节点烘焙进去。合并保留射线拾取的目的地。
- 每朵云合并其几何体；人物头发与固定衣物也在各自坐标系内合并。
- 阴影缓存而非每帧重绘；小屏关闭阴影。降低画布像素上限、限制闲时帧率，持续高渲染开销时自动使用流畅模式。
- 不再逐帧重复写入一批 DOM 属性；诊断数据定期更新。保持后台与离屏暂停、离开首页释放资源。
- 兼容场景保留同一组入口和摘橙子互动；文章页不创建 WebGL 上下文。
